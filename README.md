# Джарвис — релизы

Личное некоммерческое приложение (VPN + голосовой помощник) для телефона и ТВ‑приставки на Android.
Здесь только готовые APK и служебные файлы. Исходного кода тут нет.

**Скачать последнюю версию:** [dzharvis.apk](https://github.com/ndt-kzn/dzharvis-releases/releases/latest/download/dzharvis.apk)

- Ставится поверх прежней версии, настройки сохраняются.
- Рядом с APK лежит `version.json`: номер версии и SHA‑256 файла. Приложение само проверяет обновления (Настройки → О приложении) и сверяет SHA‑256 перед установкой.
- Тег `assets-silero-v1` — пакет голоса Silero (лицензия CC BY‑NC‑SA 4.0, только личное некоммерческое использование). Приложение скачивает его само.
